- Kullanıcının referansı: https://bestfreefonts.com/gotico-antiqua?text=piton
- Referanstaki örneğin varyantı: **Fust & Schöffer “Durandus” 118G**, Regular 400.
- Resmi kaynak: https://github.com/anrt-type/GoticoAntiqua
- Orijinal dosya: `fonts/Fust&Schoeffer-Durandus-GoticoAntiqua118G.otf`.
- Tasarım: Alexis Faudot ve Rafael Ribas, ANRT; proje yazarları `gotico-antiqua-authors.txt` dosyasında.
- Lisans: SIL Open Font License 1.1, `gotico-antiqua-license.txt`. Font değiştirilmeden, lisans ve yazar bilgileriyle saklanır.

Yalnızca geliştirme ortamındaki `/tr/font-lab` önizlemesinde kullanılır.
