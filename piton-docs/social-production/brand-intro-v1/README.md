# Piton Studios - Brand Intro V1

Instagram ve Facebook icin ortak 4:5 carousel seti.

## Teslim formati

- Olcu: 1080 x 1350 px
- Renk uzayi: sRGB
- Kaynak: `carousel.html`
- Paylasim dosyalari: `public/assets/social/brand-intro-v1/`

## Marka sistemi

- Zemin: `#0A0A0A`
- Ana metin: `#F2EFE9`
- Ikincil metin: `#D5D1C9`
- Marka kirmizisi: `#D33A3E`
- Veri mavisi: `#00A0D0`
- Sinyal mavisi: `#0870A0`
- Derin veri mavisi: `#004070`
- Baslik ve govde: JetBrains Mono
- Mikro etiketler: Press Start 2P

## Kullanim

Slaytlar sirayla yuklenir. `caption-tr.txt` gonderi metni, `alt-text-tr.txt` erisilebilirlik metnidir.
